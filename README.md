# Cc Skill Coding Standards

Universal coding standards, best practices, and patterns for TypeScript, JavaScript, React, and Node.js development.

## Overview

This repository preserves the AITMPL skill instructions and the available companion files in their original relative paths.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-cc-skill-coding-standards-skill.git ~/.claude/skills/cc-skill-coding-standards
```

On Windows, use `%USERPROFILE%\.claude\skills\cc-skill-coding-standards` as the destination.

## Usage

Claude Code can load this skill when a request matches its description. Invoke directly with `/cc-skill-coding-standards` when needed.

## Repository structure

```text
cc-skill-coding-standards/
├── SKILL.md
├── README.md
└── LICENSE
```

## Runtime requirements

- No build step or package installation is required for the instruction file.
- Check each script's imports and configuration before running it.
- Scripts and tests were not executed as part of this import.
